BastionPilot

1. Local daemon

Run bastion-pilot daemon on your machine, then paste the pairing token printed by bastion-pilot init.

2. Bastion sites

Grant BastionPilot access to the origins that host your bastion web terminal. The extension only runs on the sites you add here.

    3. Approvals & audit

    The approval mode (auto / confirm / readonly), the audit log and AI providers are configured on the daemon side in ~/.bastion-pilot/config.json. The default mode confirm shows every mutating command here or as a notification before it runs.
