本地安全控制台

BastionPilot

BP

01 本地服务

在本机运行 bastion-pilot daemon，再粘贴 bastion-pilot init 输出的配对令牌。

02 堡垒机站点

授予 BastionPilot 访问堡垒机终端站点的权限。插件只会在你添加的站点上运行。

    03 AI 服务商

    为侧边栏对话配置一个或多个 OpenAI 兼容接口。每个服务商只需要填写接口 URL 和 API Key，点击“获取模型”选择模型。配置由本地服务保存到 ~/.bastion-pilot/config.json，不会通过浏览器同步。

    侧边栏顶部可在 API Key 与 本地 Agent 之间二选一；选择本地 Agent 时不会调用这里的 API Key。

    04 审批与审计

    审批与审计由本地服务统一控制。默认严格模式会在每条终端命令、按键和文件操作前 显示审批卡片；未批准或超时都会拒绝执行。高级用户可在 ~/.bastion-pilot/config.json 中显式关闭 approval.requireUserApproval。

    05 本地 Agent 与会话

    Claude Code、Codex 等本地 Agent 可以通过 MCP 使用同一个终端、审批和审计链路，并通过共享上下文工具与侧边栏继续同一项工作。

    bastion-pilot mcp → 在 Agent 的 MCP 配置中指向上面的命令

    插件聊天记录保存在 ~/.bastion-pilot/chats/，共享上下文保存在 ~/.bastion-pilot/shared-context.json。本地 Agent 通过 MCP 连接后会出现在侧边栏，可选择具体 Codex/Claude Code 对话；Agent 用 get_shared_context 读取、用 append_shared_context 写回。
